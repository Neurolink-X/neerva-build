# Catalog photo clarity and exact SKU sourcing
- Preserve original manufacturer packaging and photograph pixels; SKU text, rights and status are shown outside the picture. Do not remove genuine product markings embedded in a photograph.
- Product-level database media cannot be treated as an exact variant photograph: label it as range media. The database currently has product-level media records, not variant-level media attribution.
- Existing audit distinguishes configured reference photographs, real locally decodable assets, illustrations and exact reviewed SKU photographs. New report enumerates every variant missing exact SKU evidence.
- Source page checked: https://commons.wikimedia.org/wiki/File:PTFE_tape.jpg (Headlock0225, CC BY-SA 4.0), generic tape only, not evidence of Viking packaging. Existing staged file remains unpublished; do not attach it as an exact branded SKU.
- Source page checked: https://commons.wikimedia.org/wiki/File:Float_switch.jpg (TankunCha, CC BY-SA 4.0), exact tank-switch type still requires visual review. Existing staged file remains unpublished. Binary visual inspection was unavailable through repository interface.
- High-resolution Magicrete and Orientbell candidates remain pending publication-rights verification. Never upscale and call it an original high-resolution photo.
- Completion requires actual dealer/manufacturer photo evidence and permitted reuse. An AI illustration is not counted as a photograph. No unverified new asset is published by this PR.
