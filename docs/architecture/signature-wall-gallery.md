# Signature Wall Gallery
The read-only artwork gallery is independent of the paint visualizer. It displays fixed local images (no canvas rasterisation, palette inputs, or remote artwork requests). Two new AI-generated interior wall crops (420 px wide) are used for geometry and luxury abstract concepts; six previously reviewed 960 px wall images are reused without duplicating public files. The magnolia image receives a fixed warm metallic treatment; no user colour controls. Total referenced source bytes: 209656. Additional committed asset bytes: 9610. Images load lazily in the grid and retain their full composition in the detail view. New room crops are compressed mobile assets, not full-resolution originals. A future higher-resolution editorial asset pass requires the original images in the repository. All entries are digital concepts and should not be advertised as actual installations.
